# Hedgehog RP TV

</div>

**Hedgehog TV** is a video platform for the Hedgehog RP universe, created to store and showcase all episodes of the “Hedgehog Chronicles”.

The platform served as the community’s central video archive, preserving the project’s history, key events, community stories, and the atmosphere of its role-playing universe. It gave all project participants convenient access to episodes and historical materials.

## ✨ Features

- Viewing all episodes of the “Hedgehog Chronicles”
- Easy navigation through the video archive
- Access to content from different seasons and periods of the project
- Centralized storage of community video content
- Display of episode information and publication dates
- Responsive interface for desktop and mobile devices

## 🔗 Related Projects

- 🦔 [Hedgehog RP](https://github.com/MaSStiK/hedgehog-rp) - main project
- 🌍 [Interactive Online Map](https://github.com/MaSStiK/map.hedgehog-rp)
- 📊 [Chat Statistics](https://github.com/MaSStiK/stats.hedgehog-rp)

## 🛠️ Technologies

- **Next.js** - Application framework and routing
- **React** - User interface
- **clsx** - Conditional CSS class composition
- **Tippy.js** - Tooltips and interactive UI elements
- **Moment.js** - Date and time handling

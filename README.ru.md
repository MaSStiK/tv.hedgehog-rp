# Hedgehog RP TV

</div>

**Ежиное телевидение** - видеоплатформа вселенной Hedgehog RP, созданная для хранения и просмотра всех выпусков «Ежиных Хроник».

Платформа служила единым видеоархивом сообщества, сохраняя историю проекта, ключевые события, истории сообщества и атмосферу его ролевой вселенной. Она обеспечивала всем участникам проекта удобный доступ к выпускам и историческим материалам.

## ✨ Возможности

- Просмотр всех выпусков «Ежиных Хроник»
- Удобная навигация по видеоархиву
- Доступ к материалам разных сезонов и периодов проекта
- Централизованное хранение видеоконтента сообщества
- Отображение информации о выпусках и датах публикации
- Адаптивный интерфейс для компьютеров и мобильных устройств

## 🔗 Связанные проекты

- 🦔 [Hedgehog RP](https://github.com/MaSStiK/hedgehog-rp) - основной проект
- 🌍 [Интерактивная онлайн-карта](https://github.com/MaSStiK/map.hedgehog-rp)
- 📊 [Статистика беседы](https://github.com/MaSStiK/stats.hedgehog-rp)

## 🛠️ Технологии

- **Next.js** - Фреймворк приложения и система маршрутизации
- **React** - Пользовательский интерфейс
- **clsx** - Условное объединение CSS-классов
- **Tippy.js** - Всплывающие подсказки и интерактивные элементы интерфейса
- **Moment.js** - Работа с датой и временем
